# Spike Legends

Anime volleyball game: story mode (Project APEX), Chemical Reactions, Flow state, custom players and teams, 2v2/3v3, 7 languages, touch + keyboard controls. Fully offline after the first load.

**Play:** https://enlightendseisai.github.io/spike-legends/

- The whole game is in `index.html`.
- `sw.js` + `manifest.webmanifest` make it installable (Add to Home Screen on iPhone, Install app on Android/PC).
- Fonts: Bangers, Teko, Nunito (SIL Open Font License, see `licenses/`).
